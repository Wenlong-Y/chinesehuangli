现代事项与黄历

黄历只有约六十种古代事项。本站把面试、签约、约会、求婚、搬家、手术、新产品发布、软件上线等现代事项对应到古代事项，并说明理由，再按《协纪辨方书》判断每天宜忌。

判断方法：对应的古代事项中只要有一项为“忌”，当日即不宜；否则有一项为“宜”，即为吉日；都没有则为平。对应关系是本站的解读，不是古书原文。

  • 新产品首发

    对应：开市、立券交易（非实体事务：不计动土类禁忌）

    首次发布即“开市”，《协纪辨方书》谓“满取丰豫之义”；对外销售兼看“立券交易”。

  • 大版本升级

    对应：修造动土（非实体事务：不计动土类禁忌）

    改建既有结构即“修造”。

  • 日常更新 / 小版本

    对应：修饰垣墙（非实体事务：不计动土类禁忌）

    “修饰垣墙”为修缮既有之物；书云平日宜之，“义取诸平”。

  • 修复漏洞 / 安全补丁

    对应：补垣塞穴（非实体事务：不计动土类禁忌）

    “补垣塞穴”，书云闭日宜之，“义取诸闭”。

  • 代码清理 / 重构

    对应：扫舍宇、解除（非实体事务：不计动土类禁忌）

    “扫舍宇”“解除”，书云除日宜之，“取除义……除旧取新”。

  • 数据 / 基础设施迁移

    对应：修仓库（非实体事务：不计动土类禁忌）

    “修仓库”，即修整储存之所。

  • 下线 / 停用产品

    对应：破屋坏垣（非实体事务：不计动土类禁忌）

    “破屋坏垣”，书云破日宜之，“义取诸破”。

  • 火箭 / 卫星发射

    对应：出行、开市

    发射即远行之始（出行），亦为大事开局（开市）。

  • 入职 / 新工作

    对应：上官赴任

    对应古代“上官赴任”。

  • 开学 / 入学

    对应：入学

    即“入学”。

  • 签约 / 成交

    对应：立券交易

    即“立券交易”。

  • 开业 / 开张

    对应：开市

    即“开市”。

  • 收款 / 投资

    对应：纳财

    即“纳财”。

  • 搬家 / 入宅

    对应：移徙、安床

    “移徙”并“安床”。

  • 装修 / 动工

    对应：修造动土

    即“修造动土”。

  • 作灶 / 安灶

    对应：修造动土

    通书把“作灶”单列一项；《协纪辨方书》六十事中没有，故按“修造动土”论。通书又有“丙不修灶”（百忌歌，本书卷三十五附录收录，但未列入本书宜忌条例），祭灶则“凡祀灶择六癸日”（卷三十五）。

  • 出行 / 出差

    对应：出行

    即“出行”。

  • 发货 / 运送货物

    对应：开仓库出货财、出行

    黄历无“运输”一项。发出货物即“开仓库出货财”，陆路运送即“出行”，二者皆不可为忌。

  • 海运 / 船运

    对应：开仓库出货财、乘船渡水

    “开仓库出货财”并“乘船渡水”，即古时水路运货。

  • 婚礼

    对应：嫁娶

    即“嫁娶”。

  • 订婚 / 领证

    对应：纳采问名、结婚姻

    “纳采问名”“结婚姻”。

  • 手术 / 治疗

    对应：求医疗病、针刺

    “求医疗病”，见血者兼看“针刺”。

  • 理发

    对应：剃头

    即“剃头”。

  • 招聘 / 领养

    对应：进人口

    即“进人口”。

  • 生日聚会 / 做寿

    对应：会亲友

    黄历无“生日”一项。办生日宴即“会亲友”。

  • 面试候选人（招聘方）

    对应：进人口（非实体事务：不计动土类禁忌）

    决定录用何人，即“进人口”。

  • 求职面试（应聘方）

    对应：上表章（非实体事务：不计动土类禁忌）

    向决策者陈述自己，即“上表章”。

  • 重要会议 / 提案 / 路演

    对应：上表章（非实体事务：不计动土类禁忌）

    向上级或投资人提出方案，即“上表章”。

  • 同房 / 备孕

    对应：求嗣、会亲友

    黄历无“同房”一项。“求嗣”指求得子嗣（古时为祈子之礼），“会亲友”指相聚。二者有宜且皆不忌之日，此处视为适宜之日。

  • 布置婴儿房 / 待产准备

    对应：修置产室、安床

    “修置产室”并“安床”，即古时产前的准备。

  • 约会

    对应：会亲友

    黄历无“约会”一项。与人相聚即“会亲友”。

  • 求婚

    对应：结婚姻

    即“结婚姻”，古时议定婚事的第一步。

  • 聚会 / 宴请

    对应：会亲友

    即“会亲友”。

  • 种植 / 园艺

    对应：栽种

    即“栽种”。

  • 丧葬

    对应：安葬

    即“安葬”。
