現代事項與黃曆

黃曆只有約六十種古代事項。本站把面試、簽約、約會、求婚、搬家、手術、新產品發布、軟體上線等現代事項對應到古代事項，並說明理由，再按《協紀辨方書》判斷每天宜忌。

判斷方法：對應的古代事項中只要有一項為「忌」，當日即不宜；否則有一項為「宜」，即為吉日；都沒有則為平。對應關係是本站的解讀，不是古書原文。

  • 新產品首發

    對應：開市、立券交易（非實體事務：不計動土類禁忌）

    首次發布即「開市」，《協紀辨方書》謂「滿取豐豫之義」；對外銷售兼看「立券交易」。

  • 大版本升級

    對應：修造動土（非實體事務：不計動土類禁忌）

    改建既有結構即「修造」。

  • 日常更新 / 小版本

    對應：修飾垣牆（非實體事務：不計動土類禁忌）

    「修飾垣牆」為修繕既有之物；書云平日宜之，「義取諸平」。

  • 修復漏洞 / 安全補丁

    對應：補垣塞穴（非實體事務：不計動土類禁忌）

    「補垣塞穴」，書云閉日宜之，「義取諸閉」。

  • 代碼清理 / 重構

    對應：掃舍宇、解除（非實體事務：不計動土類禁忌）

    「掃舍宇」「解除」，書云除日宜之，「取除義……除舊取新」。

  • 資料 / 基礎設施遷移

    對應：修倉庫（非實體事務：不計動土類禁忌）

    「修倉庫」，即修整儲存之所。

  • 下線 / 停用產品

    對應：破屋壞垣（非實體事務：不計動土類禁忌）

    「破屋壞垣」，書云破日宜之，「義取諸破」。

  • 火箭 / 衛星發射

    對應：出行、開市

    發射即遠行之始（出行），亦為大事開局（開市）。

  • 入職 / 新工作

    對應：上官赴任

    對應古代「上官赴任」。

  • 開學 / 入學

    對應：入學

    即「入學」。

  • 簽約 / 成交

    對應：立券交易

    即「立券交易」。

  • 開業 / 開張

    對應：開市

    即「開市」。

  • 收款 / 投資

    對應：納財

    即「納財」。

  • 搬家 / 入宅

    對應：移徙、安床

    「移徙」並「安床」。

  • 裝修 / 動工

    對應：修造動土

    即「修造動土」。

  • 作灶 / 安灶

    對應：修造動土

    通書把「作灶」單列一項；《協紀辨方書》六十事中沒有，故按「修造動土」論。通書又有「丙不修灶」（百忌歌，本書卷三十五附錄收錄，但未列入本書宜忌條例），祭灶則「凡祀灶擇六癸日」（卷三十五）。

  • 出行 / 出差

    對應：出行

    即「出行」。

  • 發貨 / 運送貨物

    對應：開倉庫出貨財、出行

    黃曆無「運輸」一項。發出貨物即「開倉庫出貨財」，陸路運送即「出行」，二者皆不可為忌。

  • 海運 / 船運

    對應：開倉庫出貨財、乘船渡水

    「開倉庫出貨財」並「乘船渡水」，即古時水路運貨。

  • 婚禮

    對應：嫁娶

    即「嫁娶」。

  • 訂婚 / 領證

    對應：納采問名、結婚姻

    「納采問名」「結婚姻」。

  • 手術 / 治療

    對應：求醫療病、針刺

    「求醫療病」，見血者兼看「針刺」。

  • 理髮

    對應：剃頭

    即「剃頭」。

  • 招聘 / 領養

    對應：進人口

    即「進人口」。

  • 生日聚會 / 做壽

    對應：會親友

    黃曆無「生日」一項。辦生日宴即「會親友」。

  • 面試候選人（招聘方）

    對應：進人口（非實體事務：不計動土類禁忌）

    決定錄用何人，即「進人口」。

  • 求職面試（應聘方）

    對應：上表章（非實體事務：不計動土類禁忌）

    向決策者陳述自己，即「上表章」。

  • 重要會議 / 提案 / 路演

    對應：上表章（非實體事務：不計動土類禁忌）

    向上級或投資人提出方案，即「上表章」。

  • 同房 / 備孕

    對應：求嗣、會親友

    黃曆無「同房」一項。「求嗣」指求得子嗣（古時為祈子之禮），「會親友」指相聚。二者有宜且皆不忌之日，此處視為適宜之日。

  • 布置嬰兒房 / 待產準備

    對應：修置產室、安床

    「修置產室」並「安床」，即古時產前的準備。

  • 約會

    對應：會親友

    黃曆無「約會」一項。與人相聚即「會親友」。

  • 求婚

    對應：結婚姻

    即「結婚姻」，古時議定婚事的第一步。

  • 聚會 / 宴請

    對應：會親友

    即「會親友」。

  • 種植 / 園藝

    對應：栽種

    即「栽種」。

  • 喪葬

    對應：安葬

    即「安葬」。
